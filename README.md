# Habitat 67 — Architectural Presentation

A static, GitHub Pages-ready interactive presentation about Habitat 67.

## Deploy
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. GitHub → Settings → Pages.
4. Source: **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

## Controls
- Right / Left arrows: next / previous
- Mouse wheel: next / previous
- Touch swipe on mobile
- Home / End: first / last
- Escape: close drawing viewer

## Images
The presentation intentionally uses local asset paths so the repository remains portable. Add documented images to:
- `assets/photos/`
- `assets/plans/`
- `assets/sections/`
- `assets/elevations/`
- `assets/diagrams/`

The current pages contain clearly marked placeholders where source drawings/photos should be inserted.
